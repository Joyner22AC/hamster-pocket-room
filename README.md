# 团团的小笼子 · 初代

一个静态网页仓鼠养成小游戏。打开发布链接即可玩，支持鼠标、手机触摸与键盘 1—6。美术以「豆芝麻海豹」室内 DS 养育作品的圆团造型、简单立体场景和明亮配色为参考，使用原创仓鼠、笼子和滚轮素材。

## 玩法

- 点击仓鼠或「摸摸它」互动，拖动仓鼠捧起和放下。
- 喂瓜子恢复饱腹和体力。
- 将仓鼠放上滚轮，或使用「跑滚轮」。体力过低时无法开始。
- 使用「睡一觉」或把仓鼠放到左侧小屋；拖动会唤醒，在睡眠条件下约十秒未互动后再睡。
- 困仓鼠被放到滚轮会先跑，之后在滚轮内睡着。
- 「变鼠饼」切换姿态；待机时也会走动、蜷成球、摊平和藏粮。
- 「藏一颗」触发藏粮。拖动木屑里的小鼓包换位置，仓鼠会回原处寻找，找不到会委屈；把粮食放回它身边可找回。
- 设置名字、每日睡眠区间和声音。声音由本地 Web Audio 合成，不调用外部服务。

## 存档

自动保存到 localStorage（键 hamster-pocket-room-v1），每个浏览器独立。隐藏页面和关闭时保存；离开游戏期间模拟暂停。没有帐号、后端数据库或跨设备同步。存档失败时界面提示，游戏仍可继续。

## 运行与部署

需要 Node.js，无第三方运行依赖。

```powershell
npm run dev
npm run check
npm test
```

本地地址由服务器打印，默认 http://localhost:4173。可将 dist 目录直接部署到静态托管平台。本项目 Sites 配置在 .openai/hosting.json；公开链接需要 Site access_mode 为 public。

## 验证范围

验证 JavaScript 语法、静态资源引用、WebP 文件、HTML ID 和部署入口。模拟测试覆盖昼夜睡眠区间、拖醒后十秒再次入睡、滚轮内睡觉、体力限制与喂食、挪动藏粮后的寻找/哭泣/找回、异常存档和长时间数值边界。

本轮未进行浏览器截图或真实手机触摸验收。生成素材已逐张视觉检查；页面响应式布局与指针逻辑已实现，仍需用户实际试玩反馈。可选 WebMCP 功能已做浏览器能力检测，当前没有可用的支持该 API 的验证上下文，尚未实际验证注册与调用。

## 文件

- dist/index.html、style.css：游戏界面与移动布局。
- dist/app.js：素材加载、精灵绘制、指针交互、声音、存档与可选 WebMCP。
- dist/engine.js：仓鼠状态机，与界面解耦。
- dist/assets：三张原创素材，WebP 无损编码，合计约 1.17 MiB。
- research：原版美术调研与来源。

原始精灵图集带有半透明环境光晕。渲染时对低于 246 的 alpha 做纹理遮罩，逐姿态计算轮廓边界和脚底基线；项目中的原素材 alpha 保留不变。
