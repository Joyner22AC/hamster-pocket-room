# 视觉 V2 开源资产选型

## 目标

保留现有 2D 版的可爱、温馨、柔和配色，把角色与房间升级为低模实时 3D。目标不是现代 PBR 手游，而是偏 Nintendo DS 时代的低模、手绘色块、弱透视/正交镜头和低分辨率输出。

## 已下载并验证的动画参考

### Kenney — Cube Pets 2.0
- 来源：https://kenney.nl/assets/cube-pets
- 许可：CC0。
- 本地位置：`.local/v2-assets/kenney-cube-pets/`
- 格式：FBX / GLB / OBJ。
- 共 24 个动物 GLB。
- 实测每个 GLB 都包含 8 个动画 clip：`static`、`idle`、`walk`、`run`、`eat`、`dance`、`gesture-positive`、`gesture-negative`。
- 结构特点：不是传统 skinned mesh，而是多个子节点直接做 transform animation；例如 bunny 为 `body + 4 legs` 层级，动画直接驱动节点。
- 用途：非常适合做 Three.js `AnimationMixer` 的正式轻量模板，尤其适合低模小动物。

## 推荐正式路线

### 角色

`仓鼠低模底模` → Blender 改比例 → 团团专属材质 → 清理/重绑动画层级 → 自制 Idle / Walk / Eat / Sleep / PickUp / Run 等动画 → 导出 GLB。

外形要求：
- 头略大，身体更圆更短。
- 四肢短小，脚掌稍大。
- 耳朵小且靠后。
- 鼻嘴短，眼睛略大但不要“手游大眼”。
- 保留现有团团棕背 + 奶油腹部。
- 不做写实毛发，不做高光塑料 PBR。

### 场景

`CC0 室内家具` + `现有 2D 版色板` + `项目专属滚轮 / 小窝 / 食盆`。

统一要求：
- 木色、奶油色、粉色、灰蓝/薄荷色沿用现有 2D 版。
- 家具按仓鼠尺度重做，形成微缩宠物房间。
- 核心辨识物最终使用项目专属模型。

## 正式技术管线

Blender → GLB/glTF → Three.js → AnimationMixer → 低分辨率 WebGLRenderTarget → NearestFilter → 网页显示。

现有 `engine.js` 继续负责玩法状态；3D Animation Controller 只把 `mode / pose / motion` 映射到动画 clip 和 blend。

## BOOTH ハムちゃん下载后实测（2026-09-19）

- 用户已通过正常 BOOTH 登录下载 `Ham.zip`；SHA-256：`B5111AE22DF0D34FB457C9C6C2499EC465B43FF667CA77137A5FB79195B3A488`。
- `Ham.zip` 内为 `Ham/Ham.unitypackage`。Unitypackage 实际包含 `Assets/Ham/Mesh/Ham.fbx`、`Ham.prefab`、`Ham.unity`、3 个材质以及 `Ham.png / Ham_mask.png`。
- `Ham.fbx` 为 Binary FBX，含蒙皮骨骼；转换后 GLB 为 1 个 skin、41 个 joints、43 个节点。骨骼包括 `mixamorig:Hips / Spine / Head / LeftArm / RightArm / LeftUpLeg / RightUpLeg` 等，属于 Mixamo 风格人形骨架。
- 原 FBX 没有 AnimationStack / AnimationCurve，即已经 rig，但没有现成动画 clip。
- 原模型转换后约 23,082 顶点、39,112 三角面，明显高于最终 DS 低模目标；后续需要减面。
- 原 `Ham.png` 为 2048×2048、约 4.08 MB。制作 512×512 网页版后，GLB 从约 5.62 MB 降至约 1.82 MB；同构图游戏画面区域平均像素绝对差约 `0.147/255`，因此当前网页实验采用 512 版本。
- FBX→GLB 使用本地隔离的 `FBX2glTF 0.9.7-p1`，安装在 `.local/tools/`，没有进入项目 `package.json`。
- FBX2glTF 曾把 Ham 材质写入白色 emissive，Three.js 加载层已将 emissive 清零，恢复原始灰白毛色、粉耳朵和黑眼睛。

## 当前 3D 动画验证

- `dist/v2-real-preview.html` 已实际加载 BOOTH 仓鼠 GLB + Kenney CC0 家具，Chrome Headless + SwiftShader 截图通过。
- `dist/v2-animation-lab.html` 已从兔子替身升级为仓鼠本体骨骼动画实验。
- 第一版程序生成 `idle / walk / run / eat` 四个 AnimationClip，直接驱动仓鼠 Mixamo 骨骼，并由 Three.js `AnimationMixer` cross-fade。
- 初版曾因 GLTFLoader 自动清洗 `mixamorig:Hips` 等节点名导致生成空轨道；已改为读取 `userData.name` 并兼容清洗后的节点名。修复后像素差覆盖角色区域，`Eat` 中可见前爪抬向嘴部，证明骨骼动画真实生效。
- 这四个动作仍属于第一版技术动作；下一阶段重点调整贴地感、重心、步态幅度、吃食手势，并补 `sleep / pickup / wheel`。
