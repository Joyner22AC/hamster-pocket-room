# V4 暖阳像素玩具屋风格拆解

## 目标

本轮目标不是复刻某一张图，而是把用户认可的目标画面拆解为可重复执行的视觉规则，形成适合当前静态网页仓鼠养成游戏的原创 V4 美术方向。

## 一、这张目标图为什么成立

### 1. 场景不是“笼子”，而是“可居住的小世界”

目标画面虽然仍然围绕仓鼠用品，但视觉上把它组织成了一个完整室内空间：窗户、木地板、家具、书架、植物、灯具、小屋、围栏、垫料和玩具共同构成生活环境。玩家第一眼感受到的是“家”，而不是宠物笼。

V4 规则：
- 画面主体必须是木质室内/玩具屋，不再使用大面积蓝色塑料笼壁作为主背景。
- 场景中至少同时出现窗景、木家具、植物、储物/书架、睡眠区、运动区和少量生活化小物。
- 道具密度要高，但主活动区必须保留一块清晰可玩的地面。

### 2. 光线是第一层氛围，不是最后加的滤镜

目标画面的核心情绪来自左上/窗边进入的强暖阳。高光区域接近奶油黄和金橙色，阴影保持暖棕而不是灰黑；亮部与阴影形成明显体积，同时整体仍然柔和。

V4 规则：
- 主光方向固定为左上/窗侧斜射。
- 使用金黄高光、暖棕阴影、少量偏蓝灰的冷色作为平衡。
- 地面必须有窗格/家具投影形成的明暗节奏。
- 角色脚下保留独立接触阴影，防止“贴纸感”。

### 3. “像素感”来自低频块面与边缘颗粒，不是单纯 nearest-neighbor

目标图并非传统 16-bit 像素画，而是“绘制质感 + 像素颗粒”的混合：轮廓较圆润，内部有软阴影和高光，但纹理被压缩成较大的色块，细节边缘有轻微像素阶梯。

V4 规则：
- 资产以较低逻辑分辨率绘制后 2× 放大，避免超细线条。
- 每个材质只保留少量明暗级别，不追求写实纹理。
- 木头、布料、植物使用块状纹理而不是照片纹理。
- Canvas 保持 `imageSmoothingEnabled=false`，但资产本身允许柔和渐变与局部光晕。

### 4. 景深负责制造“微缩模型”观感

目标图前景和远景都有明显虚化，主体活动区保持最清晰，形成类似移轴摄影/微缩模型的视觉效果。

V4 规则：
- 主活动区位于中景，角色和主要互动道具保持清晰。
- 前景至少有一层大尺度模糊植物/围栏遮挡。
- 背景窗外和远处装饰降低对比度与清晰度。
- 不把运行时 Canvas blur 作为关键依赖，优先预生成模糊栅格层。

### 5. 颜色不是“粉蓝可爱”，而是“木色主导 + 少量高纯度点缀”

目标图大面积使用蜂蜜木色、奶油黄、米白和暖棕；蓝色主要出现在食盆、水壶等小面积道具，绿色来自植物，粉色来自花朵/爱心/角色耳朵。

建议主色：
- 蜂蜜木：#B86F38 / #D89652 / #E9B86F
- 奶油：#FFF0C8 / #F7DFC0
- 暖棕阴影：#6A3F2B / #845038
- 植物绿：#5B743A / #86A85A
- 点缀蓝：#79A8C9
- 点缀粉：#E98586

### 6. UI 也属于世界观

目标图的 UI 使用米白卡片、圆角、深棕描边/阴影、像素化图标和温暖色条，与室内木质环境统一。UI 信息明确，但没有科技面板感。

V4 规则：
- 左侧保留竖向动作入口，但减少大面积纯白，改用奶油卡片和木色描边。
- 右上状态卡使用头像、心情和四条彩色状态条。
- 左上标题区使用木牌/奶油字形语感，但不复制目标图 Logo。
- 右下时间卡保持小尺寸、深色半透明背景。
- 手机端将左侧动作入口收成底部横向快捷栏，避免遮挡主场景。

## 二、与 V3 的差距

V3 的技术方向没有问题，但视觉上仍然是“旧笼舍素材 + 暖色 overlay”：
- 场景为空，生活化陈设不足；
- 蓝色塑料笼壁占比过高；
- 滚轮是粉色塑料，与目标图的木质世界不统一；
- 背景和前景没有真正形成微缩景深；
- UI 仍像原型说明面板，而不是成品游戏 HUD。

因此 V4 不应继续在 V3 上加滤镜，而应替换场景主美术层，同时保留 Canvas 2D、轻量加载、现有仓鼠 sprite 和可撤回独立 preview 的技术优点。

## 三、V4 第一轮可执行方案

### 栅格层
1. `v4-room-bg.webp`：暖阳木质室内背景，包含窗、墙、地板、书架、植物、睡眠小屋和静态小物。
2. `v4-room-fg.webp`：模糊前景植物/围栏遮挡，独立透明层。
3. `v4-wheel-wood.webp`：将现有滚轮重制为木质配色，并加入木纹/深浅分块。
4. 继续复用 `hamster-atlas.webp` 作为第一轮角色基底。

### 交互
- 点地面：走过去。
- 喂食：走到食盆 → 进食 → 回到活动区。
- 互动：爱心粒子 + 团球/开心姿态。
- 清理：短暂扫光/星屑反馈，清洁数值上升。
- 拍照：快门闪白 + 状态提示。
- 点滚轮：走到滚轮 → 跑轮 → 离开。
- 点睡眠小屋：走到入口 → 睡眠 → 醒来。

### 技术边界
- 不引入 Three.js/GLB/新框架。
- 不修改正式 `dist/index.html` / `dist/app.js` / `dist/engine.js`。
- 第一轮先验证“第一眼是否终于接近用户目标图”，再决定是否制作正式分层资产和接入现有 engine。
