# V8 角色自然化精修

## 目标

V8 不扩玩法，只解决 V7 仍可能残留的“直立人偶 / 塑料玩具 / 前爪外展”问题。V7 的真实 skinned hamster + AnimationMixer 技术路线保留，V8 只做角色比例、材质、镜头和骨骼表演精修。

## 静态 Art Gate

- 角色整体进一步压低、加宽，重心更靠近地面。
- 镜头改为更侧向的 3/4 视角，优先显示短鼻吻、圆背和小耳轮廓。
- 眼睛从高光纯黑改为深棕哑光，降低玩偶玻璃眼感。
- 毛发表面提高 roughness、略降低曝光，降低塑料高光。
- idle 前爪必须贴近胸前，不再横向伸展。

## 动作精修

- `breath`：髋部和胸背轻微前倾，呼吸只做局部相位变化，不整体 bob。
- `sniff`：头部先探出，再由胸背跟随，前爪保持收拢。
- `walk`：保留对侧腿节奏，但前爪仅在胸前小幅错相，不再像人类摆臂。
- `run`：加大躯干前倾，前爪缩短摆幅，腿部频率继续承担主要速度感。
- `eat / pet / pickup / drop / sleep`：沿用 V7 已通过的骨骼动作与交互桥接。

## 技术边界

- 继续使用 `dist/v2-assets-real/hamchan-cc0.glb`，1 skin / 41 joints。
- 继续使用 Three.js `AnimationMixer` cross-fade。
- 正式 `index/app/engine` 不修改；V7 不修改。
- V8 独立存档 key：`hamster-pocket-room-v8-candidate-v1`。
- 本轮只做本地候选和 QA；没有新的 commit / push / publish 授权。
