# V6 角色美术基准与关键帧方案

## 背景

V5 的核心失败不在状态机，而在角色造型：头、身体、脸颊、前爪等被拆成可见独立块，正面高度对称，两个脸颊像贴片，耳朵偏大偏高，整体更像熊/人偶面具而不是仓鼠。用户明确否定该方向。

## V6 Art Gate

V6 先要求“完全不动也必须一眼像仓鼠”，静态角色不过关禁止进入动画。造型约束：

- 小而圆的耳朵，位于头部后侧并部分被毛发轮廓遮挡；不做猫耳/大熊耳。
- 黑豆眼，缩小眼白高光比例，避免娃娃眼。
- 短鼻吻、小粉鼻、细胡须；面部下半部是一个连续的浅色毛区，不画两个独立圆形腮帮子。
- 头身视觉连续，颈部不出现机械拼接线；身体低、宽、圆滚，前爪小且贴胸口，脚掌只露少量粉色趾尖。
- 背部金棕、腹部奶油色，阴影和高光服务于体积，不暴露动画分件。

## 动画管线决策

V6 不沿用 V5 的“八组身体零件实时拼接”作为主角色方案。主动画切换为 20 帧完整角色 authored key poses + 帧间 cross-fade：

1. idle
2. sniff
3. groom
4. look
5. walk A
6. walk passing
7. walk B
8. settle
9. eat look
10. eat hold
11. eat chew
12. eat happy
13. pickup squash
14. pickup hold
15. drop impact
16. run crouch
17. run A
18. run B
19. sleep
20. pet nuzzle

完整角色帧保证每一帧单独看都保持同一只仓鼠的轮廓与面部结构。动作质量主要来自不同 authored poses、阶段 timing 与帧间过渡，而不是 whole-body bob。

## 玩法动作

- Walk：A → passing → B → passing 循环，到点用 settle 收势。
- Pet：角色本体手势识别；水平 stroke 进入 nuzzle，向上快速 stroke 为抬头反应，轻触/慢速下压为 melt。
- Pickup / Drop：idle → pickup squash → pickup hold；放下为 hold → drop impact → settle。
- Eat：look → hold → chew 往复 → happy。
- Run Wheel：idle → run crouch → run A / run B 循环。
- Idle：idle / sniff / groom / look 四种，由 hunger / energy / mood 加权选择。

## 技术边界

- 保留 Canvas 2D；不用 WebGL 作为补救。
- 新角色 atlas 为原创 raster WebP，20 帧 5×4 排列。
- V6 继续复用现有 `engine.js`，独立候选存档，不污染正式存档。
- 正式入口在用户验收 V6 前保持不变。
