# V5 角色动作与玩法规格

## Motion Art Direction

V5 的角色目标不是“更多动作”，而是让团团在每次互动中有明确意图、重量和肉感。身体是柔软的椭圆体，不是平面贴纸；头部会追随重心，耳朵、脸颊、爪子存在滞后与跟随；落地、被摸、抓食物、跑轮时必须能看到局部部件先后响应。

不可接受：整张角色图片整体 bob；无过渡 pose swap；所有动作共用同一 easing；用粒子/镜头代替角色本体表演；手势输入只换文案而不改变动作。

## Character Asset Redesign

采用原创 raster atlas `dist/v5-assets/hamster-rig-parts.webp`，固定 4×2 cell：body / head / ear / paw / foot / cheek / eye / muzzle。运行时使用 hybrid 2D rig 组合，允许每个部件独立平移、旋转、缩放与镜像。

层级：后耳/后脚 → body → 前脚 → head → cheeks → muzzle → eyes → 前耳/前爪。身体与头负责主 squash/stretch；耳朵、脸颊与爪子负责 secondary motion。视觉比例保持圆头、短腿、厚脸颊。

## Gameplay Motion Spec

- Walk：预备压低 → 左右重心轮换 → 对侧前后爪摆动 → 头部反相跟随 → 耳朵滞后 → 到点减速并 settle。
- Pet gesture：指针在角色上连续滑动；水平速度决定蹭向，向上快速滑动触发抬头眯眼，向下慢滑触发压低贴手。不是按钮触发。
- Pickup / Drop：按住后先压缩 100–160ms，再离地；离地时后脚收拢、前爪向胸口、耳朵下压；放下时脚先接触、body squash、头部滞后、再回弹。
- Eat：发现 → lean/look → 抓取 → 双爪送入口 → 脸颊交替鼓起 → 咀嚼循环 → 满足眯眼 → settle。
- Run Wheel：靠近 → 起跳/上轮 → 找平衡 → 加速 → 稳定步频 → 疲劳减速 → 下轮 → 喘气 settle。
- Dynamic Idle：至少四种：breath、sniff、groom、look-around；低能量偏 breath/groom，低饱腹偏 sniff，高心情偏 look-around。

## Motion Gate

四个核心动作 walk / pet+pickup-drop / eat / run-wheel 均必须具备 anticipation、clear key pose、arc/weight shift、secondary motion、settle。390px 移动端最低 30 FPS；浏览器不得有运行时异常。Motion Gate 通过前，不替换正式入口。
