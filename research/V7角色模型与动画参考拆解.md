# V7 角色模型与动画参考拆解

## 目标

V7 不再从“多画几帧”出发，而是先解决角色本体。用户对 V6 的核心反馈是：角色模型仍然惊悚，因此本轮先建立可爱动物角色的静态与运动基准，再进入交互实现。

## 外部参考

### Animal Crossing: New Horizons
- 官方页：https://animalcrossing.nintendo.com/new-horizons/
- 参考点：角色造型先保证清晰、友好、低攻击性的轮廓；动作服务“生活感”而非夸张炫技。
- 可迁移原则：小幅度 idle、动作前后停顿、表情和身体朝向共同传递意图。

### Little Kitty, Big City
- Steam：https://store.steampowered.com/app/1177980/Little_Kitty_Big_City/
- 公开定位中强调 cute / wholesome / 3D / cartoony / stylized，并把角色个性与探索行为绑定。
- 可迁移原则：角色必须首先是一个完整、可信的三维动物体，而不是脸部贴片或机械分件；动作应体现“动物行为”而不是 UI 状态切换。

### Kirby
- 官方页：https://kirby.nintendo.com/
- 参考点：极简但稳定的轮廓、低细节高辨识度；角色体积与姿态在小屏幕上仍清楚。
- 可迁移原则：不要用复杂细节补救错误比例；先把头身、四肢和重心关系做对。

### SPINE 动画开发资料
- 官方页：https://spine.game/
- 官方将 fluid, lifelike animations 作为技术表现重点，并公开讨论 facial animation / art direction。
- 可迁移原则：流畅感来自模型、骨骼、关键姿态、timing、blend 和次级运动的系统性组合，而不是整体 sprite bob。

## V7 Character Art Gate

1. 使用真实 skinned hamster mesh，角色本体拥有连续三维体积。
2. 小圆耳、短鼻吻、黑豆眼、短前爪、低重心必须在静态画面可读。
3. 禁止独立圆形脸颊贴片、可见机械关节、过度正面对称、夸张玩偶眼。
4. 纹理使用平滑过滤，不使用最近邻像素化把真实模型打碎成噪点。
5. 使用柔和暖色主光、冷弱补光和接触阴影，让体积通过光影而不是硬描边成立。
6. 手机 390px 下仍能看出眼、耳、鼻吻和圆润躯干。

## V7 Motion Bible

### Idle
- 不做整只角色上下浮动。
- 胸背轻呼吸，头部偶尔 2–5° 探索，前爪和脊柱有不同相位。
- 至少四种：breath / sniff / look / groom-like micro pose。

### Walk
- 四肢对侧配合，髋部有极小重心转移。
- 头部与胸背反相，形成动物步态，不做“贴图滑行”。
- 停下必须 settle。

### Eat
- 先抬头/发现 → 胸背前倾 → 双前爪向嘴 → 头部轻啄/咀嚼 → 满足停顿。
- 前爪和头部不能完全同步。

### Pet / Nuzzle
- 水平抚摸触发偏头、靠近和轻微肩背转动。
- 普通抚摸不能直接变成 pickup。

### Pickup / Drop
- 长按后拖动才进入 pickup。
- pickup：身体收拢、四肢内收、头部轻微寻找平衡。
- drop：接地缓冲 → 身体回正 → settle。

### Run Wheel
- 上轮前先前倾，跑动阶段腿部频率高于 walk，头部保持相对稳定。
- 结束后减速再 settle，不瞬间从高速切 idle。

## 技术路线

- 主模型：现有 CC0 `dist/v2-assets-real/hamchan-cc0.glb`，1 skin / 41 joints。
- 运行时：Three.js + GLTFLoader，均为项目已有本地依赖，不增加 CDN。
- 动画：程序化构建骨骼 AnimationClip + AnimationMixer cross-fade。
- 场景：继续使用 V4 暖阳木质房间 raster 作为视觉背景，避免回到 V2 低多边形家具主场景。
- 存档：复用 `engine.js`，V7 使用独立 localStorage key。

## 退回条件

如果静态截图仍出现明显熊/猫/人偶感，或小屏幕上模型脸部读不清，则停止动作扩展，先调整镜头、比例、材质和角色朝向；不得用粒子、镜头震动、UI 或更多动作掩盖模型问题。
